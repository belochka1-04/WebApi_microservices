
## Описание проекта

Миграция монолитного .NET‑приложения на микросервисную архитектуру: выделено 24 Web API‑микросервиса (Auth, Application, Job, Mask, User и др.), каждый со своим ограниченным bounded context’ом и собственным набором контроллеров. Взаимодействие между сервисами реализовано через RabbitMQ (event bus для асинхронных событий по задачам и связанным сущностям) и HTTP (typed HttpClient + IHttpClientFactory, адреса и маршруты вынесены в `appsettings.json`).

Хранение данных — в MSSQL через EF Core, доступ к API защищён JWT‑аутентификацией, настроены health‑checks, Swagger и централизованное логирование (Serilog, NLog).

## Статус и выполненные задачи 

- Выполнен перевод монолитного приложения на микросервисную архитектуру: выделено 24 Web API‑сервиса с отдельными bounded context’ами и контрактами.
- В микросервисе ApplicationService добавлены модульные/интеграционные тесты и поддержка Docker (Dockerfile, docker‑compose).
- Реализованы health‑checks для микросервисов, которые можно использовать как источник метрик доступности (для Prometheus/Grafana).
  
- Запланировано покрыть тестами остальные микросервисы .
- Планируется протестировать и выровнять поддержку Docker для всех микросервисов.
- Планируется интеграция с Prometheus и Grafana для сбора метрик и построения дашбордов на основе уже реализованных health‑checks и логов.
  
## Стек технологий

- Платформа: .NET 8, ASP.NET Core Web API.
- Язык: C#.
- Архитектура: микросервисы (24 сервиса), REST API, bounded context’ы, SOLID, DI/IoC.
- Доступ к данным: Entity Framework Core, SQL Server (MSSQL), миграции.
- Межсервисное взаимодействие: HTTP (typed HttpClient, IHttpClientFactory), RabbitMQ (event bus, очереди, обработчики интеграционных событий).
- Безопасность: JWT‑аутентификация и авторизация.
- Конфигурация: `appsettings.json`, IOptions, вынесенные URL микросервисов и маршруты.
- Логирование и наблюдаемость: Serilog, NLog, структурированные логи, health‑checks.
- Документация API: Swagger / OpenAPI.
- Контейнеризация: Docker (Dockerfile, docker‑compose), планируется унификация контейнеров для всех микросервисов.
- Тестирование: модульные и интеграционные тесты (пока частично, начиная с ApplicationService), планируется расширение покрытия.
